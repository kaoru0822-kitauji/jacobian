# v1.0 specification: stable research platform

- Status: Provisional
- Theme: Reproducible publication and independent replication

## 1. Stability promise

v1.0 stabilizes:

- artifact identity and canonicalization versioning;
- claim, witness, certificate, and result envelopes;
- checker authorization and revocation;
- plugin capability discovery;
- experiment bundle export;
- MCP tool semantics.

New assurance mechanisms may be added without reinterpreting older verified
records.

## 2. Formal-checking support

`certificate.verify` supports proof-assistant certificates, initially Lean 4.
The Lean kernel remains the proof trust anchor. Search and tactic systems remain
untrusted proposers.

Where solver encodings are used, a verified or independently checked bridge
connects the Boolean, arithmetic, or optimization encoding back to the original
domain statement.

## 3. Reproducible result bundles

A publishable bundle contains:

```text
formal claim and semantics
candidate or construction
witnesses and certificates
authorized checker identity
checker environment
artifact dependency graph
human-readable explanation
source and attribution metadata
review and replication records
```

An independent installation can replay the bundle without importing the search
engine that found it.

## 4. Collaboration and review

The platform records:

- contributors and artifact lineage;
- citations and source licenses;
- informal-to-formal correspondence review;
- checker review and signatures;
- independent replications;
- retractions and superseding results.

These records do not replace ordinary mathematical peer review. They make the
computational portion reproducible and auditable.

## 5. Operations and security

v1.0 includes:

- documented checker threat model;
- artifact and certificate size limits;
- local execution and process-lifecycle review;
- migration and backup procedures;
- compatibility and conformance suites;
- checker revocation behavior;
- denial-of-service controls;
- deterministic exact replay where the certificate format permits it.

Search reproducibility is reported precisely rather than promised universally;
parallel solvers and heuristic schedules may not reproduce identical search
trajectories.

## 6. Exit gate

v1.0 is complete when:

1. At least two independent installations replay a published bundle.
2. The stable API supports several structurally different domains.
3. A formal proof certificate is checked through the generic certificate path.
4. Revoked or mismatched checkers cannot validate new records.
5. Migration tests preserve the meaning of all earlier verified artifacts.
6. The security and trust model has received independent review.
