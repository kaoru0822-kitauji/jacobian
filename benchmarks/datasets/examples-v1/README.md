# Jacobian examples-v1

This dataset is reserved for executable, verifier-backed tutorial and smoke
workflows. It is non-comparative: completion is documentation evidence, not a
model score or mathematical benchmark.

The former pilot ledger required human review for every entry and contained no
approved examples. Those candidates are intentionally not carried into this
dataset as inert rows. Add an example only when its instruction, frozen input,
Oracle solution, and independent verifier satisfy the common task contract.
