# v0.2 specification: bounded discovery

- Status: Provisional
- Theme: Search bounded spaces and verify representation changes

## 1. Entry gate

v0.2 begins only after:

- v0.1 passes its adversarial suite;
- artifact and result schemas are exercised by both v0.1 reference domains;
- no known checker-registration or certificate-binding ambiguity remains.

## 2. New generic tools

### `search.enumerate`

Launch an exhaustive bounded search using a plugin-provided
`CandidateEnumerator`.

```json
{
  "claim_uri": "artifact://sha256/...",
  "enumerator_id": "directed-graphs.v1",
  "evaluator_id": "artifact://sha256/...",
  "bounds": {
    "vertices_max": 8,
    "arcs_max": 14
  },
  "quotient_by_isomorphism": true,
  "budget": {
    "candidates_max": 1000000,
    "wall_seconds": 3600
  }
}
```

It returns an `experiment://...` handle immediately. Progress, archive
snapshots, scope, and accounting data are available as resources.

Enumeration completeness is not inferred from the absence of candidates. A
negative mathematical result requires a checked enumeration certificate.

### `structure.canonicalize`

Compute a canonical representation, automorphism information, and orbits for a
supported finite structure.

The output is suitable for search deduplication. If canonicalization affects an
exhaustiveness claim, its correctness must be independently justified or
checked.

### `transform.apply`

Propose or compute a new representation and a proof obligation.

Supported relation labels:

```text
EQUIVALENT
OVER_APPROXIMATION
UNDER_APPROXIMATION
HEURISTIC
```

The transformer remains untrusted.

### `transform.verify`

Verify a transformation obligation and bind:

```text
source object and semantics
target object and semantics
claimed relation
obligation payload
checker digest
```

Only this tool may mark a transformation verified.

### `polytope.separate`

Perform typed exact operations over finite or implicitly represented rational
polytopes:

- convex-hull membership;
- projection;
- separation;
- H-to-V and V-to-H conversion;
- redundancy removal;
- facet and incidence computation.

Outputs remain unverified until an exact separator, dual, or conversion
certificate is accepted by `certificate.verify`.

### `experiment.cancel`

Cancel a running persistent experiment. Completed artifacts remain immutable.

## 3. Domain capabilities

v0.2 adds optional:

```text
CandidateEnumerator
Canonicalizer
Transformer
TransformationChecker
PolytopeBackend
EnumerationCertificateChecker
```

There is no separate public `structure.enumerate`; `search.enumerate`
orchestrates a domain enumerator.

## 4. Backends

Planned initial backends:

- nauty/gtools for graph generation and canonicalization;
- Z3 for bounded Boolean, integer, and rational synthesis;
- pycddlib through `cdd.gmp` for exact rational polyhedra;
- HiGHS for exploratory optimization;
- SoPlex for exact rational LP replay.

Backend status is evidence. The public conclusion is determined by Jacobian
checkers.

## 5. Cross-domain requirement

Exercise bounded discovery in both v0.1 reference domains. The non-routing
plugin must confirm that enumeration and transformation APIs do not assume:

- every candidate has a useful canonical graph label;
- mutation is mandatory;
- semantic closure is always path enumeration;
- witnesses have the same type as candidates.

## 6. Exit gate

v0.2 is complete when:

1. A bounded candidate class is enumerated with auditable scope.
2. Search deduplication rejects isomorphic duplicates.
3. A representation change is independently verified.
4. An exact rational separator is generated and checked.
5. Both reference plugins use the same core artifact and result contracts.
6. An interrupted experiment can be inspected and cancelled without corrupting
   completed artifacts.

## 7. Non-goals

- Evolutionary or learned search
- Distributed workers
- Model-uploaded code
- Automatic motif recognition
- General theorem proving
